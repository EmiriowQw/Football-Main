# UI/UX Football Day

## Основной маршрут

Расписание → дата → время и поле → отдельная страница брони → команда → число мест → позиции и имена по желанию → подтверждение. Гость может открыть страницу игры и войти через Google прямо на ней. «Мои брони» фильтрует выбранную дату и открывает тот же редактор.

## Визуальный язык

- «Ночная арена» на экранах расписания и брони: тёмно-зелёные поверхности, лаймовый акцент, линии поля и крупное время на табло. Общая тема приложения применяется на остальных экранах.
- Ближайшая доступная игра вынесена на табло, остальные поля сгруппированы по времени. Свободные места указаны текстом, на табло также показана полоса заполняемости. При открытии после последнего старта по Бишкеку показывается следующий день; прошлые игры доступны через календарь.
- Красная/синяя/жёлтая/зелёная команды обозначаются одновременно текстом и цветом. Цвет не может быть единственным индикатором.
- На странице игры время и поле видны в шапке; команда выбирается среди четырёх карточек с футболками и количеством мест. Вместимость вратаря уже включена.
- Стоимость подписана «за игрока · справочно». Не использовать кнопку «Оплатить» или статус оплаты.

## Форма брони

Количество от 1 до доступных мест команды. «Все свободные места» заполняет остаток одной команды. При редактировании собственные места включаются в доступный лимит. Команда текущей брони фиксирована: для перехода отменить и записаться заново.

Поля друзей появляются по числу N − 1. Пустые значения показываются в составе как «Гость <имя>». До подтверждения объяснить, что имена видны в составе. Во время запроса блокировать повторную отправку, сохранять введённые значения при ошибке.

Роль выбирается нажатием на точку на схеме поля. Для 4+1 расположение снизу вверх: вратарь, один защитник, два полузащитника, нападающий. Для 5+1 добавляется второй защитник. При групповой брони переключатель над схемой выбирает участника, чью роль меняем. «Без разницы» сбрасывает пожелание. Подсвечивается одна точка. Для парных ролей в бронь записывается выбранная сторона. Гость видит схему и может выбрать роль после входа.

Новая бронь завершается появлением билета после подтверждения сервером. При смене дня плавно меняется расписание, при выборе команды выделяется карточка и увеличивается футболка, при добавлении мест анимируется счётчик. Соблюдать системное отключение анимаций.

## Обязательные состояния

Загрузка, ошибка с повтором, данные из кеша, пустой список своих броней, команда заполнена, игра заполнена, собственная бронь, начавшаяся игра только для чтения, ошибка конкуренции, успешное сохранение/отмена. Не подменять недоступную БД пустыми командами с обещанием свободных мест.

## Доступность

Прокручиваемые экраны и формы при открытой клавиатуре; минимальная зона нажатия 48 dp, подписи и tooltip для иконок, контрастный текст, переносы при крупном шрифте. Проверять узкий экран 360 px, светлую/тёмную темы и RU/EN. Даты и часы показывать в часовом поясе Бишкека.
