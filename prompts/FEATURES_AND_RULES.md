# Функциональность и критерии приёмки

## Расписание

- На дату ровно шесть игр: два времени × три поля; полные игры не исчезают.
- Идентификаторы стабильны между устройствами и часовыми поясами.
- Семь будущих дней, переход к предыдущим датам для истории, обновление состояний по времени без перезапуска.

## Бронирование

- Google-пользователь выбирает одну из четырёх команд и 1..остаток мест.
- Бронь всей команды забирает только её свободный остаток.
- Нельзя разделить группу между командами или занять седьмое/шестое место.
- Имена друзей необязательны, не требуют аккаунтов; владелец занимает одно место.
- Изменение числа мест и имён возможно до старта. Для изменения команды нужна отмена.
- Отмена освобождает места в той же транзакции и обновляет всех подписчиков.
- После старта любые изменения запрещены сервером, в том числе при неверных часах клиента.
- Одновременные запросы не превышают лимит. Проигравший получает понятную ошибку и актуальный состав.

## Чего нет в этой версии

Создания игр, управления организатором, оплаты, платёжных отметок, проверки доступности у владельца поля, результатов, статистики, соцсети с видео, Telegram-синхронизации.

## Проверки перед выпуском

1. Unit: форматы 24/20, UTC+6, стабильные ID, редактирование и отмена, граничные значения.
2. Widget: расписание, форма группы, полные/прошедшие игры, гостевой просмотр, ошибки.
3. Firestore Emulator: конкуренция за остаток; чужая бронь, подмена расписания и счётчиков, прошлое время, смена команды, неправильные типы запрещены.
4. Устройство: Google-вход, потеря сети, два клиента, RU/EN, клавиатура, тёмная тема.
5. Развёртывание правил — отдельное явное действие. Локальное изменение файла не означает защиту рабочей базы.
