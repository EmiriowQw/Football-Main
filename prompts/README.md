# Документация Football Day

Начните с [AI_INSTRUCTIONS.md](AI_INSTRUCTIONS.md), затем откройте документ по задаче через [CONTEXT_ROUTER.md](CONTEXT_ROUTER.md).

- [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md) — продукт, границы версии и технический стек.
- [AI_INSTRUCTIONS.md](AI_INSTRUCTIONS.md) — обязательный рабочий процесс для разработчика и AI.
- [ARCHITECTURE.md](ARCHITECTURE.md) — слои приложения, потоки данных и конкурентное бронирование.
- [FOLDER_STRUCTURE.md](FOLDER_STRUCTURE.md) — реальные пути файлов и правила размещения.
- [UI_STYLE_GUIDE.md](UI_STYLE_GUIDE.md) — футбольный интерфейс, доступность, состояния экранов.
- [DOMAIN_MODELS.md](DOMAIN_MODELS.md) — расписание, поля, команды и брони.
- [FEATURES_AND_RULES.md](FEATURES_AND_RULES.md) — сценарии и критерии приёмки.
- [CONTEXT_ROUTER.md](CONTEXT_ROUTER.md) — какие документы читать перед изменениями.
- [SETUP_AND_TESTING.md](SETUP_AND_TESTING.md) — запуск, Firebase, проверки и ограничения.
- [IMPLEMENTATION_NOTES.md](IMPLEMENTATION_NOTES.md) — выполненные изменения, результаты проверок и примеры правил.
- [football-day-concept.md](football-day-concept.md) — исходная концепция без изменения требований.

Эта папка заменяет устаревшую документацию BasketVibe в `frontend/commands`. Исходный файл в `PROMTS` сохранён для совместимости. Все новые инструкции ведём здесь, на русском языке.
