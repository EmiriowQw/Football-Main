# Профиль и настройки

Актуальные инструкции: [PROJECT_OVERVIEW](../../../../prompts/PROJECT_OVERVIEW.md), [ARCHITECTURE](../../../../prompts/ARCHITECTURE.md).

Авторизация — Firebase Auth / Google. Настройки языка и темы доступны из Football Day. Для состава используется публичное имя Google-пользователя. Мои брони отображаются в футбольном расписании по выбранной дате.

Перед удалением аккаунта требуется отменить будущие брони. Исторические составы остаются только для чтения. Прежние профильные экраны и модели сохранены в исходниках, но не определяют бизнес-правила Football Day.
